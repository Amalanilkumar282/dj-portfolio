# Runbooks

Step-by-step procedures for things that are stressful to work out from first
principles at the time.

| Runbook                                    | When                                                  |
| ------------------------------------------ | ----------------------------------------------------- |
| [`incident.md`](incident.md)               | Something is broken in production                     |
| [`restore.md`](restore.md)                 | Data needs recovering                                 |
| [`secret-rotation.md`](secret-rotation.md) | Rotating a secret, scheduled or after a compromise    |
| [`dsar.md`](dsar.md)                       | Someone requests their personal data, or its deletion |

Keep them current. A runbook that is wrong is worse than none, because it is
followed under pressure.
